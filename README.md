# Демонстрационный сайт компании «Высота»

Рабочий статический прототип сайта-визитки со справочником частых проблем высотных работ.

## Как открыть

Откройте `index.html` двойным щелчком. Интернет нужен только для загрузки шрифтов Google; без него сайт продолжит работать с системным шрифтом.

Для запуска через локальный сервер, если установлен Python:

```powershell
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Что уже работает

- адаптивная версия для компьютера и телефона;
- навигация по разделам;
- шесть карточек клиентских проблем;
- подробные справочные материалы во всплывающих окнах;
- шесть карточек полезных статей;
- услуги;
- демонстрационные кейсы;
- FAQ;
- форма с проверкой обязательных полей;
- выбор нескольких фотографий;
- плавное появление блоков;
- мобильное меню.

## Что заменить перед публикацией

1. Телефон, город, регион и график ответа в `index.html`.
2. Фактическое описание компании, опыт, документы и условия гарантии.
3. Перечень услуг, которые компания действительно выполняет.
4. Демонстрационные кейсы на реальные объекты.
5. Графические заглушки на собственные фотографии.
6. Политику обработки персональных данных.
7. Обработчик формы: почта, Telegram, CRM или серверный API.
8. Домен, хостинг, favicon, счетчик аналитики и метаданные региона.

## Где менять статьи

Содержание справочника находится в начале `app.js`:

- `problems` — карточки проблем;
- `articles` — полные тексты;
- `articleCards` — карточки раздела «Полезное».

## Публикация

Сайт не требует сборки и может размещаться на любом статическом хостинге. Для реальной формы потребуется внешний сервис форм либо небольшой серверный обработчик.
