# «Абсолютная Высота» — рабочая версия сайта

Это копия исходного демонстрационного сайта «Высота», оформленная по предоставленной визитке. Исходная папка не изменялась.

## Что сделано

- Для первого экрана из исходной визитки создан новый фон: сохранены слово «ВЫСОТА», тросы и альпинисты у букв; верхняя чёрная полоса и напечатанный контакт удалены. Вся композиция заполняет экран без рамки.
- Красно-чёрная гамма перенесена в шапку и другие разделы.
- В шапке написано полное название фирмы «Абсолютная Высота»; в изображении ниже сохранена исходная графика со словом «ВЫСОТА».
- Имя Алексея и крупный кликабельный номер наложены обычным текстом на нижнюю часть фона, без отдельной плашки.
- Добавлены имя Алексей и телефон 8-951-762-80-99 со ссылкой для звонка.
- Сохранены существующие разделы, справочные карточки, FAQ и демонстрационная форма.
- Добавлен раздел с ориентировочными ценами для Белгорода и области; источники и ограничения расчёта сохранены в файле «Исследование цен — Белгород — 2026-09-23.md».

Откройте `index.html` двойным щелчком для просмотра. Интернет нужен только для загрузки шрифтов Google; без него используются системные шрифты.

## Что уточнить и заменить до публикации

1. Подтвердить у Алексея актуальность названия, телефона и право использовать изображение визитки.
2. Уточнить фактический регион работы, состав услуг, опыт, документы и условия гарантии.
   Согласовать с Алексеем ориентиры цен и состав работ до использования раздела как коммерческого прайса.
3. Заменить демонстрационные кейсы и графические заглушки фотографиями и описаниями реальных работ.
4. Подготовить политику обработки персональных данных.
5. Подключить реальную доставку заявок. Сейчас форма только проверяет поля и показывает демонстрационное сообщение; фотографии никуда не отправляются.
6. Проверить сайт визуально на компьютере и телефоне, затем подготовить домен и размещение.

Телефон и имя перенесены из изображения, предоставленного в чате. Остальные сведения из исходного прототипа пока не подтверждены владельцем бизнеса.
